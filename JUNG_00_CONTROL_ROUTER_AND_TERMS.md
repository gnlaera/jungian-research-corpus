## Notebook operating rules for this 10-source edition

This is an **amalgamated retrieval edition** of the Jung, Self and Relationship Laboratory. It preserves the substantive text of the original corpus while reducing the number of Notebook sources.

### Treat embedded files as separate epistemic units

Each original corpus file is enclosed between explicit `BEGIN EMBEDDED ORIGINAL CORPUS FILE` and `END EMBEDDED ORIGINAL CORPUS FILE` markers. **Do not infer theoretical identity merely because two original files now live inside the same combined source.** When answering, name the embedded original file ID and author/framework where relevant, even though the Notebook citation may point to the larger combined source.

### Evidence hierarchy

1. For claims about C. G. Jung, prefer the embedded primary-Jung reconstruction files and preserve CW paragraph references where available.
2. For a named post-Jungian author, prefer that author's embedded file and label later development or revision explicitly.
3. Keep adult attachment, Susan Johnson's attachment-centred EFT/EFCT, and Leslie Greenberg's Emotion-Focused Therapy distinct.
4. Treat original Files 26-33 as **Laboratory applied syntheses**, not as evidence that any single author proposed the integrated model.
5. Use the original File 00 and File 02 embedded in `JSRL_00` as the controlling router and terminology map.

### Epistemic labelling rule

In applied answers, explicitly distinguish when useful:

- **SOURCE CLAIM** — supported by a named author/framework;
- **LABORATORY SYNTHESIS** — a distinction, protocol, evidentiary rule, or integration constructed by this corpus;
- **APPLIED HYPOTHESIS** — a provisional interpretation of a concrete episode.

Do not convert Laboratory evidentiary thresholds into definitions belonging to Jung, attachment theory, Johnson, Greenberg, or another author. Do not state that a person is hyperactivating, deactivating, projecting, complex-constellated, operating from an inferior function, or expressing a maladaptive emotion scheme merely because behaviour resembles that formulation. Prefer language such as **one hypothesis**, **consistent with**, **would be strengthened if**, and **cannot be established from the available evidence**.

### Applied analysis discipline

Begin with observable facts and current context. Then distinguish subjective experience, recurring pattern, ordinary/contextual explanations, attachment hypotheses, complex hypotheses, emotion-process hypotheses, projection hypotheses, type hypotheses only where longitudinal evidence supports them, recursive interaction, accountability, repair/boundaries, and only then developmental/individuation hypotheses.

Do not diagnose the user or an absent partner. Do not infer attachment style, trauma, psychological type, complex, shadow, anima/animus, or unconscious motive from a single episode. Preserve actual conduct, power, safety, boundaries, accountability, and compatibility. Mutual influence does not imply equal responsibility. A deeper symbolic interpretation is not automatically better than a simpler behavioural or contextual explanation.

### Audio, video, and Studio deliverables

When generating an Audio Overview, Video Overview, briefing, study guide, FAQ, timeline, or other Studio output:

- use the thematic structure of the selected combined sources;
- preserve disagreements and framework boundaries rather than harmonising them;
- distinguish primary Jung from post-Jungian development and contemporary clinical models;
- identify important original corpus file IDs in the narration/output where useful;
- do not turn applied synthesis into author-specific doctrine;
- prefer representative depth over mentioning every embedded file superficially.

## 2. Purpose of the Laboratory

The **Jung, Self and Relationship Laboratory** is a portable, source-disciplined corpus for research into mature Jungian psychology, post-Jungian development, attachment, emotion processing, intimate relationship, and careful applied self-reflection.

The corpus is designed to answer four different classes of question without collapsing them:

1. **Historical / author-specific:** What did Jung, Fordham, Knox, Beebe, Johnson, Greenberg, or another named author actually argue?
2. **Conceptual / comparative:** How do neighbouring constructs differ across frameworks?
3. **Clinical-theoretical:** How does a specific therapy or relational model formulate distress and change?
4. **Applied / reflective:** Which hypotheses may illuminate a concrete episode, and what evidence would support or weaken each hypothesis?

The corpus is deliberately not an exhaustive archive of Jung or analytical psychology. It privileges material relevant to:

- the structure and dynamics of psyche;
- complexes and affective autonomy;
- ego, persona, shadow, anima/animus, Self;
- archetype, symbol, dreams, active imagination;
- psychological type and inferior function;
- opposites, compensation, psychic energy, and transcendent function;
- individuation;
- projection and transference;
- marriage and psychological relationship;
- developmental and relational post-Jungian revisions;
- adult attachment and affect regulation;
- emotionally focused couple therapy;
- emotion-focused experiential therapy;
- couple cycles, rupture, repair, differentiation, and dialogue.

Raw PDFs and EPUBs remain the **source vault**. The Markdown corpus is the **retrieval and research layer**. Gemini or another Notebook system is the **deployment layer**.

## 3. Corpus Design Principles

### 3.1 Retrieval quality over maximum volume

A focused question should normally activate approximately **5-10 relevant files**, not the whole corpus. Loading every file for every question increases the risk of source confusion, duplicated evidence, and framework flattening.

### 3.2 One coherent intellectual retrieval object per file

Each Markdown file is designed to be understandable as a standalone source. A file should represent a coherent author, concept cluster, chronological map, clinical model, or applied synthesis rather than an arbitrary slice of a book.

### 3.3 Primary sources control author-specific claims

If a derived corpus file conflicts with an underlying primary source, the primary source controls. Derived files are research reconstructions, not replacements for the original texts.

### 3.4 Later theory does not rewrite earlier theory

Fordham, Knox, Samuels, Schwartz-Salant, Beebe, Young-Eisendrath, Nelson and Delmedico, attachment theory, Johnson, and Greenberg may extend, revise, criticise, or reframe Jung. They are not evidence for what Jung originally meant unless Jung's own text independently supports the claim.

### 3.5 No depth premium

A symbolic, complex, archetypal, attachment, or developmental explanation is not automatically superior to an ordinary behavioural, contextual, interpersonal, medical, cultural, or practical explanation.

A useful default sequence is:

**fact -> experience -> recurring pattern -> ordinary explanation -> framework hypothesis -> competing hypotheses -> evidence for -> evidence against -> provisional interpretation.**

### 3.6 Framework interoperability without merger

The Laboratory permits several frameworks to illuminate one episode. It does not permit conceptual identity merely because two models describe similar phenomenology.

## 4. Evidence Hierarchy

Use this hierarchy whenever sources disagree or an answer risks drifting from evidence.

### Level 1 - Primary Jung

For claims about Jung, use Jung's own Collected Works and canonical paragraph references where recoverable. The main Notebook B primary spine is represented in Files 01 and 03-12.

### Level 2 - Author-specific classical / post-Jungian source

For Jacobi, von Franz, Hillman, Fordham, Samuels, Knox, Schwartz-Salant, Beebe, Young-Eisendrath, or Nelson and Delmedico, use the file dedicated to that author or work. Treat each as a later development, not as hidden primary Jung.

### Level 3 - Empirical attachment and author-specific contemporary clinical theory

Use Mikulincer and Shaver for adult attachment structure, dynamics, measurement, and the 2007 evidence base. Use Johnson 2019 for her attachment-centred psychotherapy framework. Use Johnson 2004 for detailed EFCT couple treatment. Use Greenberg 2015 for Emotion-Focused Therapy and emotion-process theory.

### Level 4 - Applied Laboratory synthesis

Files 26-33 integrate source material for reflective and comparative use. They are useful for formulation but have lower authority for author-specific historical claims.

### Level 5 - Speculative deep interpretation

Claims involving archetypal meaning, anima/animus, Self-directed purpose, typological shadow positions, another person's unconscious motive, or a hidden developmental history normally require the highest interpretive caution. Confidence should usually fall as interpretive depth rises unless evidence accumulates longitudinally.

## 5. Framework Identity Rules

The following non-equivalences govern the whole corpus.

| Construct A | Is not automatically | Why the distinction matters |
|---|---|---|
| Jungian complex | attachment style / working model | Complex theory and attachment theory organise affective repetition differently and make different developmental claims. |
| Complex constellation | strong emotion / dysregulation | Intensity alone does not establish a complex. |
| Projection | cognitive error / mind-reading / attachment expectation | Jungian projection is a specific subject-object process involving unconscious subjective participation. |
| Shadow | disliked trait | Actual ethical objection and actual harmful behaviour remain possible. |
| Anima/animus | romantic partner / gender identity | Jung's historical construct has a specific symbolic and sexed architecture and should not be casually modernised. |
| Psychological type | MBTI code / personality / compatibility | Jungian type concerns attitudes and functions of consciousness, not partner matching. |
| Inferior function | weakest skill / stress behaviour | Inferiority refers to differentiation, not competence. |
| Individuation | independence / authenticity / relationship success | Individuation concerns differentiation and relation to unconscious and Self. |
| Secure attachment | individuation | Security and individuation answer different developmental questions. |
| Internal working model | complex / projection | Similar effects on expectation do not establish theoretical identity. |
| Emotion scheme | complex / working model | Greenberg's construct belongs to a different emotion-process model. |
| Johnson EFCT | Greenberg Emotion-Focused Therapy | Historically related lineages with different mature organising frameworks. |
| EFCT negative cycle | complex-to-complex interaction | One is an attachment-centred systemic formulation; the other is a Jungian applied hypothesis. |
| Schwartz-Salant relational field | EFCT negative cycle | Field theory and attachment-cycle theory are not the same level of explanation. |
| Dialogue | agreement / EFCT enactment | Dialogue may preserve genuine difference and can reveal incompatibility. |
| Repair | reconciliation / forgiveness / relationship preservation | Repair can occur without continuation and continuation can occur without full repair. |
| Mutual interaction | equal responsibility | Recursive influence does not erase asymmetry of conduct, harm, or power. |

- 17 Knox: attachment-informed emergent mind;
- 18 Schwartz-Salant: relational field;
- 19 Beebe: eight-function typology;

- 22 empirical adult attachment;
- 23 Johnson's 2019 attachment-centred psychotherapy framework;

### 7.5 Applied synthesis layer

**26-33** are the applied research interface.

They should normally be activated only after or alongside relevant theoretical feeders. They are designed to generate hypotheses, competing explanations, and reality checks rather than diagnosis.

## 15. Applied Episode Analysis Protocol

For real relationship episodes, use this sequence.

### Step 1 - Observable event

What happened in language that could in principle be recorded by a camera or verified independently?

### Step 2 - Context

Fatigue, pain, illness, substance use, workload, prior conflict, financial pressure, cultural context, timing, and practical stakes can matter before depth interpretation.

### Step 3 - Subjective experience

What emotion, body state, thought, image, memory, urge, or meaning was directly experienced?

### Step 4 - Present reality

What did the other person actually do? Was an agreement broken? Was there actual unavailability, dishonesty, threat, incompatibility, or boundary violation?

### Step 5 - Attachment hypothesis

Was felt availability, responsiveness, proximity, support, or security threatened? Are hyperactivating or deactivating processes plausible?

### Step 6 - Complex hypothesis

Does the episode show recurrence, strong affective charge, stereotyped interpretation, historical resonance, narrowed flexibility, associative clustering, or interference with conscious intention?

### Step 7 - Emotion-process hypothesis

What emotion is present? Is Greenberg's distinction among primary adaptive, primary maladaptive, secondary, or instrumental emotion useful? What evidence supports that classification?

### Step 8 - Projection hypothesis

What quality or motive has been attributed to the other? What evidence supports it? What evidence contradicts it? Does a recurring subjective image exceed current evidence?

### Step 9 - Type hypothesis

Only after stable longitudinal evidence: could habitual differences in orientation, perception, or judgment contribute to misattunement?

### Step 10 - Recursive interaction

How did one person's behaviour become the other's event? Did a repeated loop form? Do not infer equal responsibility merely because the sequence is recursive.

### Step 11 - Accountability

What did each person actually do? What impact followed? What must be owned regardless of psychological explanation?

### Step 12 - Repair / boundary / decision

What requires acknowledgement, changed behaviour, reassurance, dialogue, boundary, restitution, trust rebuilding, or acceptance of incompatibility?

### Step 13 - Developmental hypothesis

Only last ask whether the episode participates in projection withdrawal, greater differentiation, individuation, or another developmental process.

## 16. Self-Analysis Guardrails

The Laboratory supports structured reflection. It must not:

- diagnose the user or another person;
- infer an attachment style from one interaction;
- infer trauma from strong emotion;
- treat a complex as a literal inner personality;
- treat every disliked trait as shadow;
- treat every attraction as anima/animus projection;
- infer Beebe archetypal positions from isolated behaviour;
- turn type into fixed identity or compatibility scoring;
- use "Self" as an oracle that validates what the ego already wants;
- use individuation language to rationalise avoidance, impulsivity, cruelty, or self-centredness;
- make symbolic interpretation more authoritative than observable facts.

A useful confidence ladder is:

**observable fact -> direct self-report -> recurring pattern -> psychological hypothesis -> deep symbolic/archetypal hypothesis.**

Confidence normally decreases from left to right unless evidence accumulates.

## 17. Couple-Analysis Guardrails

When analysing intimate relationships:

- analyse patterns before assigning motives;
- do not diagnose an absent partner;
- do not infer attachment orientation from cycle position;
- `pursuer != anxious attachment`;
- `withdrawer != avoidant attachment`;
- `introvert != withdrawer`;
- a real partner may genuinely possess a quality that is also projected upon;
- projection can coexist with betrayal, incompatibility, or harmful conduct;
- recursive interaction does not imply equal responsibility;
- mutual influence does not neutralise power differences;
- actual violence, coercion, intimidation, stalking, sexual boundary violation, or serious control must not be reframed as "two complexes" or "a negative cycle";
- vulnerability is not required where safety is absent;
- repair does not require forgiveness, reconciliation, or continuation;
- staying is not inherently more individuated than leaving;
- leaving is not inherently more individuated than staying.

# Jung, Post-Jungian, Attachment, and EFT Terms and Concept Map

## Source and scope note

This file is the terminology-control layer for the **Jung, Self and Relationship Laboratory**. It is designed to answer a deceptively difficult question before applied interpretation begins: **what does a term mean in the framework that actually uses it?**

The Laboratory works across theories that often describe overlapping human events but do not mean the same thing by them. A fight between partners can simultaneously be described as a complex constellation, attachment-system activation, a negative interaction cycle, secondary emotion obscuring primary vulnerability, projection, typological misattunement, or participation in a relational field. Those descriptions are not interchangeable. They select different units of analysis, propose different mechanisms, and imply different questions.

The evidence order in this file is therefore explicit:

1. **C. G. Jung's own published texts** control claims about Jung's technical concepts and their historical development.
2. **Classical and post-Jungian authors** control their own revisions, extensions, and disagreements with Jung.
3. **Adult attachment theory** is treated as a distinct empirical and theoretical tradition, represented here primarily by Mario Mikulincer and Phillip R. Shaver and, for clinical translation, Susan M. Johnson.
4. **Emotionally Focused Couple Therapy (EFCT)** refers here to the attachment-centred couple-therapy lineage associated with Susan Johnson. The abbreviation EFCT is used when the couple modality is meant, even when Johnson's sources use the broader acronym EFT.
5. **Emotion-Focused Therapy** refers here to Leslie Greenberg's emotion-process tradition. It is not silently merged with Johnson's EFCT.
6. **Contemporary Jungian couples work** is represented especially by Eowyn Nelson and Anthony Delmedico, while relational and field-oriented post-Jungian developments are routed to Young-Eisendrath, Schwartz-Salant, Knox, Fordham, Samuels, Beebe, and Meier as appropriate.
7. **Laboratory synthesis** is always secondary. It may place concepts side by side, but it does not retroactively claim that one author anticipated another framework in full.

This is a reference source, not a diagnostic manual. A term may help formulate a hypothesis about an episode. It does not establish that a person "has" a particular complex, attachment style, inferior-function problem, or archetypal configuration. Applied use should preserve the difference between observation, interpretation, competing explanations, and what remains unknown.

### Edition and extraction note

The primary Jung base consists of the Project copies of *Psychological Types* (CW 6), *Two Essays in Analytical Psychology* (CW 7), *The Structure and Dynamics of the Psyche* (CW 8), *The Archetypes and the Collective Unconscious* (CW 9i), *Aion* (CW 9ii), *Psychology and Alchemy* (CW 12), *Mysterium Coniunctionis* (CW 14), *The Practice of Psychotherapy* (CW 16), and *The Development of Personality* (CW 17). Canonical Collected Works paragraph numbers are given only where they were recoverable with adequate confidence from the Project texts.

The Project's adult attachment monograph is Mikulincer and Shaver's 2007 *Attachment in Adulthood: Structure, Dynamics, and Change*. It is a major integrative source but should not be treated as a complete account of evidence published after 2007. Johnson's *The Practice of Emotionally Focused Couple Therapy* is the 2004 second edition; *Attachment Theory in Practice* is the 2019 volume. Greenberg's Project source is the 2015 second edition of *Emotion-Focused Therapy: Coaching Clients to Work Through Their Feelings*. Young-Eisendrath's *Love Between Equals* is the 2019 book. Nelson and Delmedico's *The Art of Jungian Couples Therapy* is the 2026 Routledge volume.

## How to use this file

Use this file first when a Notebook query contains a word that belongs to more than one framework. A good research sequence is:

1. identify the **observed event** in ordinary language;
2. identify which framework's term is being proposed;
3. read the technical definition here;
4. follow the source routing to the relevant dedicated corpus file;
5. compare at least one plausible alternative formulation before treating the first interpretation as explanatory.

For example, "I suddenly became cold and detached during conflict" is an observation. It might be explored as attachment deactivation, a defensive response to complex activation, an affect-regulation strategy, an introverted retreat, a secondary emotional process, or a relational-field event. The observation does not, by itself, determine which account is best.

Use **primary Jung terms historically**. Jung's anima/animus formulations, for example, are explicitly sex-differentiated and historically gendered. This file describes that position rather than rewriting it into contemporary gender theory. Later revisions are then identified as later revisions.

Use **attachment terms dimensionally**, not as personality essences. Anxiety and avoidance are orientations or strategies that can vary by relationship and context. Do not infer them from one argument.

Use **clinical process terms operationally**. An EFCT negative cycle describes patterned interaction under attachment threat. A Greenbergian secondary emotion describes an emotional response that reacts to or defends against a more primary process. Neither should be converted into a Jungian archetype merely because the same episode can be described in both languages.

## Evidence and framework labels

The following labels are used at conceptual boundaries:

- **[JUNG PRIMARY]**: definition or distinction grounded directly in Jung's published work.
- **[CLASSICAL JUNGIAN]**: clarification by a close classical expositor such as Jolande Jacobi or Marie-Louise von Franz.
- **[POST-JUNGIAN DEVELOPMENT]**: an explicit later development, revision, or extension.
- **[ATTACHMENT THEORY]**: adult attachment concepts and research model.
- **[EFCT]**: Susan Johnson's attachment-centred Emotionally Focused Couple Therapy.
- **[EMOTION-FOCUSED THERAPY]**: Leslie Greenberg's emotion-process model.
- **[CONTEMPORARY JUNGIAN COUPLES]**: concepts from contemporary Jungian couples practice.
- **[CORPUS SYNTHESIS]**: Laboratory comparison or routing statement rather than an author's own construct.
- **[INTERPRETIVE CAUTION]**: a point at which concept-merging, diagnosis, or overclaiming is especially likely.

## Part I - Core Jungian Terms

### Psyche

**[JUNG PRIMARY] Compact definition.** The psyche is Jung's broad empirical field of psychological life. It includes conscious and unconscious processes and cannot be reduced to the conscious ego. Jung repeatedly treats psychic events as phenomena worthy of investigation in their own right rather than as mere epiphenomena of physiology. In *On Psychic Energy*, he argues provisionally for treating the psyche as a relatively closed system for psychological inquiry while leaving the psychophysical relation unresolved [Jung, CW 8, §§7-11].

**Technical meaning.** "Psyche" is wider than everyday "mind." It includes affects, fantasies, images, dreams, complexes, attitudes, functions, unconscious dispositions, and symbolic processes. In later Jung, it also has boundary concepts such as the psychoid that complicate any simple equation of psyche with introspectively accessible mental content.

**Distinguish from.** The psyche is not the ego; it is not identical with consciousness; it is not simply the brain; and it is not a synonym for the Self. The Self is a specific totality-and-ordering concept within Jung's map of the psyche.

**Applied relevance.** A self-analysis that starts from "what do I consciously intend?" is only an ego-level inquiry. A Jungian question adds: what autonomous affect, dream, fantasy, bodily reaction, or repeated relational pattern suggests a psychic process not yet included in the ego's account?

**Primary routes.** CW 8; CW 6 definitions; Corpus Files 03, 04, 08.

### Consciousness

**[JUNG PRIMARY] Compact definition.** Jung defines consciousness as the relation of psychic contents to the ego insofar as that relation is perceived by the ego [Jung, CW 6, §700]. A content can therefore be psychic without being conscious.

**Technical meaning.** Consciousness is relational rather than a container holding the whole psyche. The ego is its reference centre. Jung's developmental and individuation models assume that consciousness can widen, differentiate, and alter its relation to unconscious material.

**Distinguish from.** Consciousness is not the Self, total personality, rationality, moral goodness, or complete self-knowledge. Becoming conscious of a projection does not mean the whole source of the projection has been exhausted.

**Couple relevance.** In "Marriage as a Psychological Relationship," Jung links psychological relationship to the capacity for conscious distinction between self and other and argues that relationship is limited to the extent that important material remains unconscious [Jung, CW 17, §§324-327]. The formulation is historically Jung's and should not be imported wholesale into contemporary couple science, but it remains useful for distinguishing actual encounter from largely projected encounter.

### Ego

**[JUNG PRIMARY] Compact definition.** The ego is the complex of ideas that forms the centre of the field of consciousness and has a high degree of continuity and identity [Jung, CW 6, §706].

**Technical meaning.** The ego is necessary for orientation, continuity, choice, discrimination, and the capacity to relate consciously to unconscious material. It is itself a complex, although a central one. Jung's later psychology does not aim to abolish the ego; it aims to relativise the ego's claim to be the whole personality.

**Development.** In early life the ego-conscious field develops and differentiates. Jung's mature individuation model gives greater emphasis to the ego's relation with a wider totality, the Self. Fordham later revised Jungian developmental thinking by locating self-processes much earlier in infancy; that is a post-Jungian development, not a statement Jung himself made in Fordham's terms.

**Distinguish from.** Ego is not selfishness; ego strength is not inflation; ego is not Self; ego-consciousness is not the whole psyche.

**Applied warning.** "My ego wants X" can become a vague moral label. Prefer concrete questions: what position is conscious, what does it protect, what evidence contradicts it, and what unconscious material seems to challenge it?

### Unconscious

**[JUNG PRIMARY] Compact definition.** Jung's broad definition covers psychic contents and processes that are not conscious, plus unconscious dispositions and forms that may never previously have been conscious [Jung, CW 6, §837].

**Technical meaning.** Jung differentiates the **personal unconscious** from the **collective unconscious**. The unconscious is not merely a storage place for repressed material. It also has compensatory, prospective, imaginal, and pattern-forming dimensions in Jung's model.

**Distinguish from.** Do not equate unconscious with irrational, bad, traumatic, instinctual, or unknowable in every respect. Some contents become conscious; others are inferred indirectly from effects.

### Personal unconscious

**[JUNG PRIMARY] Compact definition.** The personal unconscious consists largely of contents deriving from individual life, including forgotten, repressed, subliminal, or insufficiently conscious material. In Jung's formulation, its characteristic structural units include feeling-toned complexes. Jung contrasts this with the collective unconscious in *The Concept of the Collective Unconscious* [Jung, CW 9i, §§87-90].

**Relationship relevance.** Personal history can load present partners with meanings generated by earlier experiences. A Jungian account calls attention to complexes and projection; attachment theory describes learning in internal working models. These may overlap phenomenologically without being the same theoretical construct.

### Collective unconscious

**[JUNG PRIMARY] Compact definition.** Jung describes the collective unconscious as the impersonal layer of the unconscious that does not derive from the individual's personal acquisition and whose structural forms are archetypes [Jung, CW 9i, §§87-90].

**Technical meaning.** "Collective" does not mean currently shared group opinion. It refers to universal or species-wide inherited formal dispositions in Jung's theory. Particular mythic images are not themselves inherited as ready-made photographs in the simplest reading; Jung distinguishes archetype-as-such from the variable images through which archetypal pattern becomes manifest.

**Later revision.** Jean Knox explicitly reconstructs archetype developmentally and emergently, bringing attachment, cognitive science, and image-schema theory into the discussion. That is a substantive post-Jungian reinterpretation, not evidence that Jung's original model was already an attachment model.

### Feeling-toned complex / complex

**[JUNG PRIMARY] Compact definition.** In *A Review of the Complex Theory*, Jung defines a feeling-toned complex as an emotionally accentuated image of a psychic situation that is incompatible with the habitual conscious attitude, has strong inner coherence, and possesses a degree of autonomy [Jung, CW 8, §201].

**Constellation.** A complex is **constellated** when a situation touches its affective core and the complex becomes functionally active. Jung describes this activation as disrupting conscious intention, attention, memory, and ordinary freedom of response; one discovers that complexes can "have" us rather than simply being contents we possess [Jung, CW 8, §200].

**Autonomy.** Complexes can behave like relatively independent partial personalities. At stronger intensities they may temporarily assimilate ego functioning, producing identification with the complex [Jung, CW 8, §§202-204]. This is a structural claim in Jung's psychology, not a diagnosis of dissociative identity disorder.

**Development.** Jung's complex theory begins in his association experiments and remains foundational. Post-Jungians rework it relationally and developmentally. Samuels, for example, emphasises complex as a network of meaning and relationship rather than a static named object. Knox links affective relational experience and internal working models to developmental patterning without equating those models with complexes.

**Distinguish from.** A complex is not simply a strong emotion, bad habit, attachment style, trauma diagnosis, schema, archetype, or personality type. A complex may contain archetypal patterning, personal memories, affects, bodily reactions, fantasies, and relational expectations.

**Self-analysis relevance.** A useful complex hypothesis asks for repeated evidence: What trigger reliably narrows attention? What affect arrives disproportionately fast? What old meanings become certain? What action tendency becomes compelling? What alternative information disappears? What happens afterward when the affect subsides?

**Couple relevance.** Conflict can become **complex-to-complex** rather than ego-to-ego interaction: each partner responds partly to activated inner configurations rather than only to present data. Contemporary Jungian couples work develops this formulation explicitly. It should be tested alongside attachment activation and interaction-cycle accounts.

**Primary routes.** [Jung, CW 8, §§200-204]; Files 03 and 28.

### Constellation

**[JUNG PRIMARY] Compact definition.** Constellation is the activation of a psychic configuration, especially a complex, by a situation that touches its affective nucleus. The word describes a dynamic event, not merely the existence of the complex.

**Distinguish from.** "I have a mother complex" names a hypothesised structure. "The interaction constellated the complex" describes activation. Attachment theory's **attachment-system activation** also describes activation under threat, but the system, mechanism, evidence base, and expected patterns are different.

### Affect and emotion

**[JUNG PRIMARY] Compact definition.** Jung defines affect as a feeling state marked by bodily innervation and a disturbance of the normal sequence of ideas; he treats "emotion" as substantially synonymous with affect in this technical definition [Jung, CW 6, §681]. Affect can therefore indicate that psychic energy has shifted beyond ordinary ego control.

**Feeling is not affect.** Jungian **feeling** is one of the four functions of consciousness and is a rational function of value judgment. It is not synonymous with emotion. This distinction is essential for type work [Jung, CW 6, §723].

**Cross-framework warning.** Greenberg's emotion categories and Johnson's attachment emotions are much more differentiated clinical process concepts. Do not assume that Jung's "affect" maps one-to-one onto primary adaptive, primary maladaptive, or secondary emotion.

### Autonomy of the complex

**[JUNG PRIMARY]** The phrase refers to the empirical impression that a complex can function with relative independence from conscious intention, interrupt association, alter memory and attention, and produce behaviour experienced as partly alien to the usual ego position [Jung, CW 8, §§200-204].

**Interpretive caution.** Autonomy is relative, not proof that a literal separate person exists inside the psyche. Personification can be clinically or imaginally useful without requiring ontological reification.

### Dissociation

**[JUNG PRIMARY] Compact definition.** Dissociation is a splitting or loosening of connection among psychic systems or contents. Jung's complex theory assumes that the psyche is dissociable and that complexes can behave as splinter psyches. His later writings also use dissociation more broadly in discussing psychic structure.

**Distinguish from.** Jungian dissociation is a broad structural concept and should not be automatically converted into a current psychiatric dissociative disorder. Nor is every moment of emotional withdrawal evidence of dissociation.

**Relational relevance.** Strong conflict can narrow consciousness and split off incompatible positions. Fordham, Knox, and contemporary trauma-informed Jungians add developmental accounts. EFCT and attachment theory use different constructs to describe shutdown, deactivation, or loss of effective co-regulation.

### Persona

**[JUNG PRIMARY] Compact definition.** The persona is the socially adaptive mask or role-system through which the individual meets collective expectations. Jung calls it a segment of the collective psyche and a compromise between the individual and society about what one should appear to be [Jung, CW 7, §§243-246].

**Technical meaning.** Persona formation is necessary. The problem is not having a persona but identifying with it so completely that role, status, competence, virtue, or social image is mistaken for the whole personality.

**Distinguish from.** Persona is not simply "fake self," lying, impression management, or Winnicott's false self. Those comparisons may be illuminating but belong to different theories.

**Couple relevance.** Intimate relationships expose discrepancies between public identity and less integrated needs, affects, vulnerabilities, and shadow material. A partner can become the witness to aspects that a social persona cannot easily accommodate.

### Shadow

**[JUNG PRIMARY] Compact definition.** The shadow names aspects of personality that the conscious ego does not recognise or accept as itself. In *Aion*, Jung treats confrontation with the shadow as an accessible first encounter with unconscious personality and emphasises its moral and affective difficulty [Jung, CW 9ii, §§13-18].

**Technical meaning.** Shadow includes traits and tendencies incompatible with the conscious self-image. It is not restricted to socially "bad" material. Vitality, assertiveness, tenderness, dependency, ambition, eroticism, creativity, or moral capacities can be shadowed if the conscious identity excludes them.

**Projection.** Unrecognised shadow qualities are readily attributed to others. Jung stresses that projection itself is unconscious; it is not a deliberate act of assigning one's traits to someone else [Jung, CW 9ii, §§16-17].

**Distinguish from.** Shadow is not simply repressed emotion, trauma, attachment avoidance, "toxic traits," or everything one dislikes in another. A disliked trait may be accurately perceived. Shadow becomes a useful hypothesis when the affective charge, repetition, one-sided certainty, and self-exemption suggest that something about the observer also requires investigation.

**Couple relevance.** Partners are unusually effective carriers of disowned material because intimacy supplies repeated emotional contact and high stakes. Contemporary Jungian couples therapy uses the couple's shared and individual shadow explicitly, but a shadow interpretation should not erase actual behaviour, power, boundaries, or harm.

### Archetype

**[JUNG PRIMARY] Compact definition.** Archetype refers to an inherited formal disposition or patterning factor of the collective unconscious. Jung distinguishes the archetype as such from the concrete archetypal images through which it becomes represented in consciousness. In *The Concept of the Collective Unconscious*, archetypes are the structural forms of the collective unconscious [Jung, CW 9i, §§87-90].

**Technical meaning.** The archetype is not a fixed mythic picture stored in the brain. Images, motifs, fantasies, affects, and behavioural tendencies may constellate around a pattern, but their cultural and personal form varies. Jung increasingly treats archetypes in relation to instinct, pattern formation, numinosity, and eventually psychoid boundary questions.

**Development and dispute.** Jung's archetype concept changes over decades and contains more than one model. Jean Knox makes this internal plurality explicit and proposes a developmental-emergent reinterpretation. Contemporary handbooks continue to debate biological, developmental, symbolic, cultural, and relational readings.

**Distinguish from.** Archetype is not stereotype, role, personality type, universal image, attachment style, or a label to explain any emotionally powerful event.

### Archetypal image

**[JUNG PRIMARY]** An archetypal image is a representational manifestation shaped by an archetypal disposition plus the person's historical and cultural material. This distinction protects against treating specific inherited images as the archetype itself.

**Examples of form rather than diagnosis.** Recurrent motifs of mother, child, hero, trickster, wise old person, death-rebirth, mandala, or conjunction may be considered archetypal when their form, affective intensity, and symbolic reach warrant it. Naming a motif is the beginning of inquiry, not an explanation of the individual case.

### Image / fantasy image

**[JUNG PRIMARY]** Jung's technical "image" is not merely a sensory after-image. It is a psychic representation or fantasy-image. A primordial image has mythological character [Jung, CW 6, §743]. Images can mediate between conscious and unconscious processes and are central to dreams and active imagination.

### Symbol and sign

**[JUNG PRIMARY] Compact definition.** Jung distinguishes a **symbol** from a sign. A sign points to something already known; a living symbol is the best currently possible expression for something that remains partly unknown or not yet fully formulable [Jung, CW 6, §814].

**Technical meaning.** A symbol is not a secret code with a fixed dictionary translation. Its psychological value depends on the person's associations, context, compensatory relation to consciousness, and wider parallels. A dream snake does not mean the same thing in every dream.

**Distinguish from.** Symbol is not symptom, allegory, diagnostic indicator, universal code, or proof of an archetype. A symbolic interpretation should expand the field of meaning rather than prematurely close it.

### Libido / psychic energy

**[JUNG PRIMARY] Compact definition.** Jung's mature energic usage broadens libido beyond Freud's sexual libido into **psychic energy**. In *On Psychic Energy* he treats energy as an abstract way of describing quantitative relations, gradients, transformations, and movement within psychic processes rather than a literal substance [Jung, CW 8, §§1-12; see also CW 6, §778].

**Development.** The meaning of libido changes across Jung's break with Freud. A mature Jungian use should therefore avoid taking every early use as identical with the later general-energy concept.

**Applied relevance.** Questions about where interest, affect, fantasy, or attention repeatedly flows can be useful. "Energy" should not become pseudo-physics. Jung himself distinguishes psychological use from demonstrated physical energy conversion.

### Instinct

**[JUNG PRIMARY]** Instinct denotes inherited patterns of action and motivation at the biological end of Jung's model. In later work Jung places instinct and archetype in close relation, roughly as inherited action-pattern and inherited form of psychic apprehension. This relation is discussed especially in "Instinct and the Unconscious" and "On the Nature of the Psyche" in CW 8.

**Distinguish from.** Instinct is not impulse in the everyday sense and not the same as attachment-system activation. Attachment theory is an evolutionary behavioural-system model with specific proximity, safe-haven, and secure-base functions.

### Psychoid

**[JUNG PRIMARY] Compact definition.** "Psychoid" is a difficult later boundary term used when Jung is discussing archetypal and instinctual factors at a level not fully representable as ordinary psychic contents. It points toward a limiting zone where the distinction between psyche and material process cannot be treated as simple.

**Interpretive caution.** Psychoid does not license paranormal certainty, vague "energy" claims, or the assertion that interpersonal feelings are literally transmitted by an established physical field. Later field theorists may draw analogies, but those analogies remain later constructions.

**Primary route.** CW 8, "On the Nature of the Psyche"; File 06 and, for relational field comparison, File 18.

### Numinosum / numinous

**[JUNG PRIMARY] Compact definition.** Jung borrows the language of numinosity to describe experiences that seize consciousness with an affective force experienced as greater than ordinary ego intention. Archetypal contents often have this compelling quality.

**Distinguish from.** Numinous does not mean true, morally good, supernatural, or therapeutic. An experience can be psychologically overwhelming and still be misleading, destructive, or in need of discrimination.

### Compensation

**[JUNG PRIMARY] Compact definition.** Compensation describes the tendency of unconscious processes to complement or counterbalance a conscious attitude. In his dream theory Jung argues that dreams contribute to psychic self-regulation by bringing forward what consciousness has neglected, undervalued, repressed, or does not know [Jung, CW 8, §§466, 483-495].

**Not simple opposition.** Compensation can confirm, qualify, correct, deepen, or counter a conscious position. Jung explicitly warns against treating dream compensation as a simple rule with a fixed opposite meaning.

**Relationship relevance.** A relationship may constellate qualities that a person's established identity has excluded. That does not mean the partner exists merely to "balance" the individual, nor does it excuse harmful dynamics as psychologically necessary.

### Enantiodromia

**[JUNG PRIMARY] Compact definition.** Jung adopts Heraclitus's term for a "running counter to": an extreme one-sided conscious tendency can eventually call forth its unconscious opposite [Jung, CW 6, §708].

**Distinguish from.** Enantiodromia is not a law that every attitude automatically flips, nor an excuse for volatility. It is a dynamic image for the compensatory consequences of sustained one-sidedness.

### Self

**[JUNG PRIMARY] Compact definition.** The Self is Jung's empirical concept for the totality and unity of the personality, encompassing conscious and unconscious and therefore exceeding the ego [Jung, CW 6, §789]. In later works it also functions as an ordering and centring principle represented through symbols of wholeness.

**Technical meaning.** The Self is both difficult to represent and central to Jung's mature individuation model. It is approached symbolically through mandalas, quaternities, divine-child and other totality motifs, not directly possessed as an object by the ego.

**Ego-Self distinction.** In *Aion*, Jung warns against both inflation of the ego by assimilation to the Self and reduction of the Self to the ego [Jung, CW 9ii, §§43-47]. Individuation therefore requires a differentiated relation, not egoic capture of "my true Self."

**Distinguish from.** Self is not self-esteem, identity, personality, ego, authentic self, attachment security, or a perfected endpoint. Fordham's **primary self** is a later developmental construct with a different emphasis.

**Couple relevance.** A Jungian relationship frame asks whether the bond supports or obstructs each person's wider psychic development, while also allowing the relationship itself to become a site of symbolic and relational transformation. This is not the same criterion as satisfaction or attachment security, though those can matter greatly.

### Participation mystique

**[JUNG PRIMARY] Compact definition.** Borrowing Lévy-Bruhl's term, Jung uses participation mystique for a mode of relation in which subject and object are insufficiently differentiated and participate in a partial psychic identity [Jung, CW 6, §781].

**Relationship relevance.** It can describe states of fused assumption: "If I feel it, you must mean it" or "your difference is experienced as betrayal of our shared identity." It should not be used to pathologise ordinary empathy, intimacy, dependency, or attachment.

**Cross-framework distinction.** Fusion-like relationship states can also be explored through attachment anxiety, weak reflective function, projective identification, or an EFCT cycle. Those accounts are not synonyms.

### Conscious / conscious content

**[JUNG PRIMARY]** "Conscious" describes a psychic content that stands in a perceived relation to the ego. It is therefore more precise than using conscious as a synonym for deliberate, rational, or morally responsible. Something can be intended but poorly reflected upon, and something can become conscious without being accepted or integrated. See consciousness [Jung, CW 6, §700].

### Autonomous complex

**[JUNG PRIMARY]** An autonomous complex is a complex whose relative independence from the ego is especially evident. It interrupts intention, captures attention and affect, and can behave as though it has a viewpoint of its own. "Autonomous" is a statement about functional independence, not proof of a separate literal personality [Jung, CW 8, §§200-204].

### Ego complex

**[JUNG PRIMARY]** The ego itself is a complex, but the central complex of consciousness. Calling it the ego complex protects against imagining the ego as an unconditioned observer outside psychic life. It also helps explain why ego positions can be emotionally defended and historically formed while still serving the necessary functions of identity and continuity [Jung, CW 6, §706].

### Archetype-as-such

**[JUNG PRIMARY]** The archetype-as-such is the hypothetical, non-representable formal disposition underlying variable archetypal images. It cannot be observed directly; it is inferred from recurring forms of imagery, affect, fantasy, and behaviour. This distinction is essential because the represented mother, hero, mandala, or trickster image is already culturally and personally shaped.

### Primordial image

**[JUNG PRIMARY]** Primordial image is an earlier Jungian term for an image with mythological, collective character. It overlaps historically with the developing archetype concept but should not be used to erase Jung's later distinction between archetype-as-such and archetypal representation [Jung, CW 6, §743].

### Symbolic attitude

**[JUNGIAN METHOD]** A symbolic attitude is the stance that treats an image, symptom, dream, or event as potentially expressing more meaning than its literal or already-known explanation exhausts. It requires openness without credulity. It does not mean assuming that everything is symbolic or preferring symbolic meaning to factual explanation.

### Myth

**[JUNGIAN / ARCHETYPAL]** Myth is a culturally elaborated narrative form in which archetypal motifs can become visible. Jung uses mythology comparatively to amplify dreams and psychic processes. A personal episode resembling a myth does not mean the person is literally enacting that myth; the comparison is heuristic and symbolic.

### Motif

**[JUNGIAN / COMPARATIVE]** A motif is a recurrent thematic or imagistic pattern, such as descent, rebirth, sacred marriage, abandoned child, journey, or trickster encounter. Motifs are useful for amplification but are less theoretically specific than archetypes. Repetition of a motif does not by itself establish an archetypal mechanism.

### Synchronicity

**[JUNG PRIMARY]** Synchronicity is Jung's term for a meaningful coincidence in which events are connected by meaning rather than by a demonstrated causal chain. It belongs primarily to CW 8's late essay "Synchronicity: An Acausal Connecting Principle." For this Laboratory it is a boundary concept only. It should not be used to interpret every coincidence in a relationship as fate, confirmation, or guidance, and it contributes little to ordinary couple-process analysis unless the meaningful-coincidence problem is itself the research question.

## Part II - Psychological Type

### Psychological type

**[JUNG PRIMARY] Compact definition.** Psychological type is Jung's model of recurrent differences in orientation of consciousness. Its basic architecture combines two **attitudes**, introversion and extraversion, with four **functions**, thinking, feeling, sensation, and intuition. Each function can operate in an introverted or extraverted attitude, creating eight function-attitudes as later authors such as Beebe emphasise [Jung, CW 6, ch. X and Definitions].

**What type is for.** Type is a model of characteristic orientation, not a complete personality description. Jung developed it partly to understand systematic differences in perspective, including disagreements among psychological schools. The model also helps explain one-sided development: consciousness tends to differentiate some modes strongly while others remain relatively inferior or unconscious.

**Distinguish from MBTI.** The Myers-Briggs Type Indicator operationalises and modifies Jung's typology for assessment. The four-letter MBTI code is not identical to Jung's original theory, and Jung did not formulate the later J/P coding convention. Beebe uses MBTI notation where useful but explicitly builds a depth-psychological model beyond the instrument.

**Couple relevance.** Type can illuminate recurrent mismatches in what each partner notices, how each evaluates, how quickly each seeks closure, and what form of communication feels self-evident. It should not be used to tell a partner what they are, excuse behaviour, or convert conflict into immutable compatibility categories.

### Introversion

**[JUNG PRIMARY] Compact definition.** Introversion is an inward turning of libido or interest toward the subject and subjective factor [Jung, CW 6, §769]. In the introverted attitude, subjective conditions have greater determining weight in orientation.

**Not social shyness.** An introvert in Jung's sense can be socially capable, expressive, or assertive. Social withdrawal may arise from many causes unrelated to typology.

**Couple relevance.** Under stress, an introverted orientation may be experienced by an extraverted partner as withholding or retreat, while the introverted partner may experience external pressure as invasive. This is a typological hypothesis only. Attachment deactivation, fear, conflict learning, fatigue, or a complex may better explain a given episode.

### Extraversion

**[JUNG PRIMARY] Compact definition.** Extraversion is an outward turning of libido or interest toward the object and objective conditions [Jung, CW 6, §710].

**Not sociability.** Extraversion concerns orientation, not simply talkativeness, parties, or social confidence.

**Couple relevance.** Extraverted orientation can favour thinking aloud, engaging the external situation, and seeking response. In a conflict, this can interact badly with a partner who needs inward processing time. Do not automatically translate this into attachment pursuit.

### Function

**[JUNG PRIMARY] Compact definition.** A psychological function is a characteristic form of psychic activity that remains theoretically consistent despite changing contents [Jung, CW 6, §731]. Jung's four basic functions answer different orienting questions: thinking concerns conceptual relations, feeling evaluates value, sensation registers what is present, and intuition apprehends possibilities or relations through unconscious perception.

### Thinking

**[JUNG PRIMARY] Compact definition.** Thinking is the rational function that connects representations conceptually and reaches judgments by conceptual relations [Jung, CW 6, §830].

**Distinguish from intelligence.** A thinking preference does not mean greater intelligence, rationality in the everyday sense, emotional coldness, or factual correctness. Feeling is also rational in Jung's technical sense.

**Couple relevance.** Thinking may organise conflict around consistency, reasons, criteria, or causal structure. A partner using feeling may be evaluating worth, appropriateness, loyalty, or relational value. Each may misread the other's mode as defective rather than differently organised.

### Feeling

**[JUNG PRIMARY] Compact definition.** Feeling is a rational judging function that accepts or rejects, values or devalues [Jung, CW 6, §723]. It is not the same as affect or emotion.

**Critical distinction.** A person can be a differentiated feeling type without being highly emotional, warm, empathic, or expressive. Conversely, an intense affective person may have poorly differentiated feeling judgment.

**Couple relevance.** Feeling judgments can be experienced by a thinking-oriented partner as insufficiently reasoned, while thinking judgments can be experienced as relationally blind. The Laboratory should ask what evaluative criterion is operating rather than caricaturing either function.

### Sensation

**[JUNG PRIMARY] Compact definition.** Sensation is a perceptive function that establishes that something is present through sensory registration [Jung, CW 6, §792]. It attends to actuality, concrete givens, bodily and environmental data.

**Distinguish from sensuality.** Sensation is not equivalent to sexual interest, materialism, impulsiveness, or bodily awareness in general.

### Intuition

**[JUNG PRIMARY] Compact definition.** Intuition is perception mediated through the unconscious. It apprehends possibilities, origins, tendencies, and relations that are not given directly to conscious sensation [Jung, CW 6, §770].

**Distinguish from mystical certainty.** Intuition can be accurate or inaccurate. Its psychological form does not guarantee truth. In relationships, intuitions about a partner require reality testing.

### Rational and irrational functions

**[JUNG PRIMARY]** Thinking and feeling are **rational** because their characteristic operation is judgment. Sensation and intuition are **irrational** because their characteristic operation is perception rather than judgment. "Irrational" here is technical and non-pejorative; it does not mean foolish or unreasonable [Jung, CW 6, §§774, 785].

### Superior / principal function

**[JUNG PRIMARY] Compact definition.** The superior or principal function is the most differentiated conscious function, the mode most reliably available to the ego for adaptation. It often becomes strongly identified with competence and conscious identity.

**Developmental problem.** The very success of the superior function can produce one-sidedness. Jung's discussions of superior and inferior functions stress that culture rewards differentiated capacities while neglected functions remain less adapted and more unconscious [Jung, CW 6, §§101-115 and ch. X].

### Auxiliary function

**[JUNG PRIMARY] Compact definition.** The auxiliary function supports the principal function while differing in kind. In Jung's mature type description, a rational principal function is normally supported by an irrational auxiliary, or vice versa; the auxiliary remains subordinate to the principal [Jung, CW 6, ch. X, "The Principal and Auxiliary Functions"].

**Later development.** Myers-Briggs theory formalises attitude relations among functions more rigidly than Jung did. Beebe then develops a specific eight-position model in which the auxiliary carries a parental archetypal role. That is Beebe's model, not a hidden table Jung himself supplied.

### Tertiary function

**[POST-JUNGIAN DEVELOPMENT]** The tertiary function is implicit in a four-function hierarchy but receives much more explicit structural treatment in later type traditions. Beebe associates it with child, puer, or puella imagery and positions it opposite the auxiliary on the "arms" axis of his model.

**Interpretive caution.** Tertiary-function language should not be treated as a universally validated developmental stage or as a diagnosis of immaturity.

### Inferior function

**[JUNG PRIMARY / CLASSICAL JUNGIAN] Compact definition.** The inferior function is the least differentiated function relative to the dominant conscious orientation. It remains closer to the unconscious, more archaic, affect-laden, and difficult to employ voluntarily. Jung treats neglected inferior functions as a consequence and counterweight of one-sided differentiation; he argues that they ultimately demand recognition rather than permanent repression [Jung, CW 6, §§108-115].

Marie-Louise von Franz makes the clinical importance especially vivid: the inferior function is a major "door" through which unconscious figures and transformative material enter. It may carry spontaneity, awkwardness, fascination, vulnerability, and disproportionate affect precisely because it is not under the same conscious discipline as the superior function.

**Distinguish from incompetence.** Inferiority is structural, not a score of ability. A person may have learned substantial skills in the inferior domain while the function remains psychologically charged. Conversely, poor skill does not prove inferior-function status.

**Couple relevance.** Partners often carry capacities each has neglected. Early attraction can therefore feel liberating: the other seems to perform what one does not readily do. Von Franz notes the danger of distributing functions within families and marriages so that one person "does" a function for the other. Later development may destabilise that arrangement when an individual needs to reclaim the neglected function.

**Cross-framework warning.** Inferior-function activation can look like dysregulation but is not identical to it. Attachment activation, trauma response, complex constellation, or simple lack of skill may explain the same behaviour.

### Differentiation

**[JUNG PRIMARY] Compact definition.** Differentiation is development from fusion toward distinct, specialised functioning [Jung, CW 6, §705]. A differentiated function can operate with greater clarity and relative independence rather than being mixed indiscriminately with other functions.

**In individuation.** Jungian development requires both differentiation and relationship among differentiated parts. Differentiation is therefore not emotional distance, defensive detachment, or radical self-sufficiency.

**Cross-framework distinction.** Attachment avoidance can create distance without psychological differentiation. Conversely, secure attachment can support differentiation by making difference safer.

### One-sidedness

**[JUNG PRIMARY] Compact definition.** One-sidedness is over-development or over-identification with a conscious attitude or function at the cost of excluded alternatives. Jung treats it as both a cultural necessity for specialised adaptation and a source of compensatory pressure from the unconscious.

**Indicators.** Rigid certainty, chronic devaluation of the opposite function, repeated relational irritation at others who carry the disowned mode, and compensatory dreams can all suggest one-sidedness. None is individually decisive.

### Function-attitude

**[POST-JUNGIAN TERMINOLOGICAL CLARIFICATION]** A function-attitude combines one of Jung's four functions with introversion or extraversion, yielding eight forms: introverted thinking, extraverted thinking, introverted feeling, extraverted feeling, introverted sensation, extraverted sensation, introverted intuition, and extraverted intuition. Beebe uses "function-attitude" as a central organising term for his eight-function model.

### Distorted or falsified type

**[CLASSICAL JUNGIAN / POST-JUNGIAN]** Von Franz describes people whose natural dominant orientation has been distorted by environmental pressure, for example a child pushed to cultivate a function that fits family expectations rather than spontaneous disposition. Beebe also discusses falsification of type.

**Interpretive caution.** This is not a licence to declare that a person's reported type is "false" whenever behaviour is inconsistent. Type assessment is uncertain, context-sensitive, and easily contaminated by role demands and self-image.

### Typological misattunement

**[CORPUS SYNTHESIS]** This Laboratory term describes recurring misunderstanding plausibly arising from differences in function or attitude rather than from ill will. Examples include one partner offering conceptual analysis when the other is making a value judgment, one seeking concrete detail while the other speaks in possibilities, or one processing inwardly while the other expects visible engagement.

It is a **hypothesis class**, not a Jungian technical term. It belongs to applied File 30 and should be tested against attachment threat, complex activation, communication history, power, and the actual content of disagreement.

---

### Attitude type

**[JUNG PRIMARY]** Attitude type refers to the broad introverted or extraverted orientation before function preference is specified. A complete Jungian type formulation normally requires both attitude and function.

### Dominant function

**[LATER TYPE TERMINOLOGY]** "Dominant" is common later shorthand for Jung's superior or principal function. The terms are broadly compatible, but this file prefers superior/principal when making claims directly about Jung.

### Undifferentiated function

**[JUNG PRIMARY]** An undifferentiated function is mixed with other functions and unconscious material, works inconsistently, and lacks the relative autonomy and refinement of a differentiated function. Inferior functions are characteristically less differentiated, but any function can be underdeveloped or contaminated by other processes.

### Eight function-attitudes

**[JUNGIAN / BEEBE CLARIFICATION]** Jung's four functions each occur in introverted and extraverted forms, yielding eight function-attitudes. Beebe makes those eight explicit as a full depth-psychological cast and assigns each an archetypal position. The eight forms are grounded in Jung; the fixed eight-position archetypal architecture is Beebe's development.

### Shadow functions

**[BEEBE]** Shadow functions are the four function-attitudes occupying positions five through eight in Beebe's model. They are more ego-dystonic and often appear defensively through opposing, senex/witch, trickster, or demonic/daimonic modes. "Shadow function" here is Beebe's technical extension and should not be treated as Jung's own general synonym for inferior function.

### Type one-sidedness

**[JUNGIAN]** Type one-sidedness is overreliance on the preferred conscious attitude and functions, with chronic depreciation or unconsciousness of their opposites. It is one route by which typology becomes relevant to individuation: the aim is not perfect equal use of all functions but a less unconscious relation to excluded modes.

## Part III - Individuation, Symbol and Transformation

### Individuation

**[JUNG PRIMARY] Compact definition.** Individuation is the process by which a person becomes a psychological individual, a differentiated unity or whole rather than merely a bearer of collective expectations. Jung explicitly distinguishes it from individualism: individuation realises one's particular form while also establishing a more adequate relation to collective life [Jung, CW 7, §§266-269; see also CW 6, §757].

**Development.** Jung's mature writing often foregrounds individuation in the second half of life, after ego adaptation and social establishment have developed substantially. Post-Jungians such as Fordham extend individuation into infancy and childhood through different developmental models.

**Not a wellness programme.** Individuation can involve conflict, loss of persona certainty, encounter with shadow, withdrawal of projection, integration of opposites, and new ethical responsibilities. It is not synonymous with happiness, independence, authenticity, self-actualisation, or doing whatever feels personally true.

**Relationship relevance.** Relationship can further individuation by forcing differentiation between actual other and projected image, exposing complexes and shadow, and requiring new capacities. It can also become a defence against individuation if one partner is used to carry excluded psychic functions indefinitely. None of this means separation is inherently more individuated than commitment.

**Cross-framework distinction.** Attachment security concerns the organisation of proximity, safety, support, and exploration in close bonds. Secure attachment may facilitate individuation, but it is not individuation itself.

### Individualism

**[JUNG PRIMARY]** Individualism privileges supposed individual interests or peculiarities over collective obligations. Jung distinguishes it from individuation, which he presents as a better fulfilment of individual and collective demands through becoming what one specifically is [Jung, CW 7, §267].

**Common misreading.** Leaving relationships, rejecting norms, or asserting personal preference is not automatically individuation.

### Opposites

**[JUNG PRIMARY] Compact definition.** Opposites are polar tendencies that structure psychic conflict and energy: conscious/unconscious, introversion/extraversion, thinking/feeling, sensation/intuition, persona/shadow, masculine/feminine in Jung's historical formulations, and many symbolic polarities. Psychic energy depends on tension or difference between positions.

**Developmental meaning.** Jungian work does not simply choose the "better" pole. It differentiates the opposites, sustains tension sufficiently for symbolic transformation, and seeks a new relation not reducible to mechanical compromise.

### Tension of opposites

**[JUNG PRIMARY]** The tension of opposites is the experienced conflict produced when incompatible but psychologically significant positions are held rather than prematurely resolved by repression, acting out, or one-sided identification.

**Applied relevance.** Examples include autonomy and dependence, truth and care, commitment and freedom, stability and novelty. The Jungian question is not "Which side wins?" but whether a third symbolic or practical attitude can emerge without falsifying either pole.

### Transcendent function

**[JUNG PRIMARY] Compact definition.** Jung defines the transcendent function as the psychological function arising from the relation and eventual union of conscious and unconscious contents [Jung, CW 8, §131]. Because conscious and unconscious tendencies are typically non-identical and compensatory, their encounter can make a transition to a new attitude possible [Jung, CW 8, §§132, 145-146].

**"Transcendent" does not mean supernatural.** Jung explicitly says the term is not metaphysical. It is analogous to a mathematical function in the sense of linking different domains or positions [Jung, CW 8, §131].

**Process.** The ego first recognises the conflict rather than suppressing one side. Unconscious material is given form, often through fantasy, image, dream, writing, drawing, or active imagination. Consciousness then responds. A symbolic product or new attitude may emerge that changes the relation between the opposites.

**Distinguish from compromise.** A fifty-fifty behavioural bargain may be useful but is not necessarily a transcendent function. The key is transformation of the psychic configuration, not negotiated arithmetic.

**Cross-framework distinction.** Greenberg's emotional transformation involves changing maladaptive emotion through activation and processing of adaptive emotion. EFCT restructures attachment interaction through new emotional engagement. These can be psychologically transformative, but they are not the Jungian transcendent function unless the Jungian mechanism is independently established.

### Active imagination

**[JUNG PRIMARY] Compact definition.** Active imagination is a method for engaging emerging unconscious material while retaining conscious participation. The person allows images, figures, affects, or fantasies to develop and then enters a deliberate relation with them rather than passively drifting or immediately interpreting them.

**Role.** It is a principal method for creating the dialogue from which the transcendent function can emerge. It can take visual, verbal, dramatic, bodily, or artistic form.

**Safety and limits.** Jung himself warned that active imagination can be destabilising when unconscious material overwhelms ego functioning; his 1958/59 note to "The Transcendent Function" explicitly rejects treating the method as a harmless game. It is not simply free fantasy or positive visualisation.

**Couple relevance.** Active imagination is primarily intrapsychic. Using it to imagine a partner must not replace actual dialogue with the partner. An imagined figure is evidence about one's psyche, not privileged access to the other person's mind.

### Dream

**[JUNG PRIMARY] Compact definition.** For Jung, the dream is a spontaneous psychic product that presents unconscious material in imagistic form. Dreams have a compensatory relation to the conscious situation and may sometimes show prospective tendencies [Jung, CW 8, §§466, 483-495].

**Method.** Jung rejects fixed symbol dictionaries. Interpretation attends to the dream's precise images, the dreamer's associations, the conscious context, recurring motifs, and amplification where appropriate.

**Couple relevance.** A partner appearing in a dream is not automatically a literal statement about the partner. The figure may represent actual relationship data, subjective qualities, projection, complex material, or several levels simultaneously.

### Amplification

**[JUNGIAN METHOD] Compact definition.** Amplification expands the possible meaning of an image by placing it beside relevant mythological, religious, cultural, historical, or symbolic parallels. It is especially useful when personal associations do not exhaust an image's structure.

**Distinguish from free association.** Amplification does not simply follow any chain of associations away from the image. It circles the image and compares structurally relevant parallels.

**Risk.** Symbolic erudition can swamp the person's actual life. Amplification should deepen the image's psychological relevance, not replace lived context with mythology.

### Prospective function

**[JUNG PRIMARY]** Jung distinguishes the prospective aspect of dreams from compensation. Prospective material anticipates possible future conscious achievements, like a preliminary sketch of a solution, without constituting literal prediction [Jung, CW 8, §§492-494].

**Common misreading.** Prospective does not mean prophetic certainty.

### Mandala

**[JUNG PRIMARY] Compact definition.** Mandala is a circular or quaternary totality image that Jung repeatedly associates with centring, ordering, and symbolic representations of the Self. It becomes especially important in CW 9i and CW 12.

**Interpretive caution.** A circular drawing is not automatically a Self symbol, and a mandala image does not prove that individuation is "complete." Context and sequence matter.

### Coniunctio

**[JUNG PRIMARY] Compact definition.** Coniunctio is the alchemical conjunction or union of opposites. In Jung's later work it becomes a major symbolic model for psychic integration, especially in *The Psychology of the Transference* and *Mysterium Coniunctionis*. The process includes separation, conflict, transformation, and forms of union; it is not simply romantic fusion [Jung, CW 16, "The Psychology of the Transference"; CW 14, ch. VI].

**Historical development.** Jung first uses alchemical conjunction to illuminate transference and then gives the symbolism a much broader mature treatment in CW 14. Schwartz-Salant later places the coniunctio more explicitly in an interactive relational field.

**Distinguish from.** Coniunctio is not marriage satisfaction, orgasm, secure attachment, reconciliation, "soulmate" union, or agreement. It can symbolise an intrapsychic integration that occurs within, through, or partly against the fate of an actual relationship.

### Alchemical transformation

**[JUNG PRIMARY]** Jung uses alchemy as a historical symbolic matrix through which projected psychic processes can be studied. Core motifs include prima materia, separatio, nigredo, conjunction, death, purification, return of soul, and new birth. He does not propose literal laboratory alchemy as psychotherapy.

**Couple relevance.** Jung's transference essay maps the analyst-analysand relation through Rosarium imagery. Later relationship theorists extend alchemical metaphors to couples. Such extensions should be labelled as later applications.

---

### Integration

**[JUNGIAN]** Integration means bringing differentiated unconscious material into a workable relation with consciousness without simply assimilating it to the ego's old position. It is not fusion, homogenisation, or disappearance of conflict. Jungian integration preserves difference while increasing the personality's capacity to contain it.

### Assimilation of unconscious contents

**[JUNG PRIMARY]** Assimilation refers to taking unconscious contents into conscious relation. Jung warns that indiscriminate assimilation can produce inflation if the ego identifies with collective or Self-like contents. The task is conscious relation and discrimination, not swallowing the unconscious into ego identity [see CW 7, Part One, ch. II; CW 9ii, §§43-47].

### Third / third thing

**[JUNGIAN / POST-JUNGIAN]** The "third" is a recurrent way of naming what emerges when a genuine opposition is held rather than solved by victory of one pole. In Jung, the transcendent function provides the clearest mechanism for a new attitude arising between conscious and unconscious. Schwartz-Salant later uses "third thing" or "third area" relationally for the field between people. These uses are related but not identical.

### Conjunction

**[JUNG PRIMARY]** Conjunction is the general symbolic idea of joining differentiated opposites. **Coniunctio** is the specifically alchemical form that becomes central in Jung's late work. Not every integration is a coniunctio, and conjunction does not imply fusion without difference.

### Wholeness

**[JUNG PRIMARY]** Wholeness refers to the wider totality of personality symbolised by the Self, including mutually opposed conscious and unconscious elements. It is not perfection, faultlessness, completion, or permanent harmony.

### Centring

**[JUNGIAN]** Centring names a movement toward a more ordered relation around a wider psychic centre than the habitual ego position. Mandala imagery often symbolises centring. It is a descriptive-symbolic process, not evidence of literal energy moving to a geometric centre.

### Circumambulation

**[JUNGIAN / SYMBOLIC]** Circumambulation is Jung's image for repeatedly circling a difficult centre or symbolic problem rather than solving it linearly. It is relevant to mandala and Self symbolism and to the iterative character of individuation. In this Laboratory it is a secondary term, not a fixed therapeutic technique.

## Part IV - Projection, Transference and Relationship

### Projection

**[JUNG PRIMARY] Compact definition.** Projection is an unconscious process by which a subjective psychic content appears to belong to an external object. Jung's account stresses that projection is not consciously manufactured; it is recognised as projection only retrospectively, when discrepancy or analysis makes the subjective contribution visible [Jung, CW 9ii, §§16-17].

**The carrier or hook.** Projection need not mean the external person has none of the projected quality. Jungian and post-Jungian writers often speak of a "hook": something in the object may correspond to the projected content. The analytic task is not to prove the other innocent but to discriminate what belongs to the other, what belongs to the subject, and what has arisen in interaction.

**Withdrawal of projection.** Withdrawal means reclaiming the subjective component previously experienced as wholly located in the other. C. A. Meier emphasises that this requires more than recognising a hook: one must also inquire into the inner projection-making factor. Jung links shadow, anima/animus, and other unconscious factors to projection.

**Relationship relevance.** Attraction, contempt, idealisation, jealousy, moral certainty, or repeated disappointment can all involve projection. But high emotion alone is insufficient evidence. Actual betrayal, incompatibility, kindness, competence, danger, and power remain real-world possibilities.

**Distinguish from internal working model.** An attachment internal working model is a learned cognitive-affective organisation of self, others, and attachment interaction. Projection is a psychodynamic attribution process. Working models can bias perception without being "projections" in Jung's technical sense.

### Projection-making factor

**[JUNG PRIMARY / MEIER CLARIFICATION]** The projection-making factor is the unconscious configuration that generates or sustains a projection. In *Aion*, Jung treats anima/animus as major projection-making factors after shadow work [Jung, CW 9ii, §§19-29]. Meier develops a triadic view in which subject, projection carrier, and projection-making factor must all be considered.

### Withdrawal of projection

**[JUNGIAN PROCESS]** To withdraw a projection is to recognise and integrate the subject's contribution without denying the object's reality. Mature withdrawal increases discrimination: "this quality is partly mine" rather than "I imagined everything."

**Couple application.** It should lead to more accurate encounter with the actual partner. If the conclusion merely flips from idealisation to total self-blame, projection has not been usefully worked through.

### Subject-object relation

**[JUNGIAN / MEIER] Compact definition.** Subject-object relation concerns how a person as subject relates to, affects, perceives, and is affected by the object. Meier stresses reciprocity: in actual analytic relationship, subject and object influence one another, complicating a one-way projection model.

**Relational implication.** Some interactions cannot be understood by assigning all psychologically significant content to one person's intrapsychic projection. The encounter itself can alter both participants. This insight opens toward later field theories without making those later theories identical to Jung's model.

### Transference

**[JUNG PRIMARY] Compact definition.** Transference is the displacement or projection of psychologically charged relational contents into the therapeutic relationship. Jung regards it as a central phenomenon of deep analysis but resists reducing all therapeutic change to transference alone. In his mature view, the analyst and patient enter a reciprocal dialectical process [Jung, CW 16, §1 and "The Psychology of the Transference"].

**Jung's distinctive emphasis.** Transference can contain personal projections and archetypal material. Jung's Rosarium analysis uses alchemical conjunction imagery to represent the mutual transformation that can occur when unconscious material is activated between analyst and analysand.

**Distinguish from attachment bond.** A therapist can function as a security-providing attachment figure in attachment research. That does not make attachment and transference equivalent. Transference theory asks about displaced and projected relational meanings; attachment theory asks about behavioural-system organisation, security, proximity, and internal working models.

### Countertransference

**[JUNGIAN / POST-JUNGIAN] Compact definition.** Countertransference refers to the therapist's psychological response to the client and to the transferential field. Jung's dialectical model recognises that the analyst is affected and transformed by the encounter. Later developmental and relational Jungians make systematic use of countertransference as information while also warning that the therapist's own complexes can distort it.

**Distinguish from certainty.** Feeling something strongly in the therapist does not prove that the client "put" it there. The response may derive from the therapist, the client, the interaction, or several levels at once.

### Psychological relationship

**[JUNG PRIMARY] Compact definition.** In "Marriage as a Psychological Relationship," Jung argues that psychological relationship presupposes sufficient consciousness and differentiation between self and other; where large areas remain unconscious, relation is limited by primitive identity and projection [Jung, CW 17, §§324-327].

**Historical limitation.** The essay contains period-specific heterosexual, sex-essentialist, and cultural assumptions. Its conceptual value for this Laboratory lies in consciousness, projection, differentiation, and midlife transformation, not in treating its gender statements as contemporary empirical facts.

### Marriage as a psychological relationship

**[JUNG PRIMARY]** Jung distinguishes legal/social marriage from the psychologically conscious relation between partners. He describes early marital harmony as often supported by unconscious archetypal projection and argues that midlife can expose the inadequacy of seeking inner completion solely through the partner [Jung, CW 17, §§324-340].

**Contained and container.** Jung proposes a historical model in which a more "simple" and a more "complex" personality can fall into contained/container positions [Jung, CW 17, §§331-334]. This model is not a current diagnostic typology and should be used cautiously. Its enduring question is whether one partner is carrying psychological complexity, autonomy, or completion that the other has not yet developed inwardly.

### Anima

**[JUNG PRIMARY, HISTORICALLY GENDERED] Compact definition.** In Jung's classical formulation, the anima is a feminine soul-image or personification of unconscious relational life in a man and a major projection-making factor. It is closely linked to feeling, eros, fantasy, mood, and the contrasexual other in Jung's historical binary model [Jung, CW 6, §808; CW 9ii, ch. III; CW 17, §338].

**Development.** The concept changes across Jung's work and becomes deeply embedded in projection, individuation, and symbolic relationship with the unconscious. Later Jungians have criticised, revised, pluralised, or de-gendered the concept in different ways.

**Do not silently modernise.** Saying "anima is simply anyone's inner feminine" both preserves and distorts Jung: it keeps gender polarity while detaching it from his explicit sex-differentiated theory. Contemporary use must state what has been revised.

**Couple relevance.** Jung saw passionate attraction and aversion as frequent sites of anima projection [Jung, CW 17, §338]. The practical aim is greater discrimination between the actual partner and the inner image, not devaluation of attraction as "only projection."

### Animus

**[JUNG PRIMARY, HISTORICALLY GENDERED] Compact definition.** In Jung's classical formulation, the animus is a masculine personification or inner figure in a woman, associated historically with logos, opinion, spirit, and a plurality of masculine images. It also functions as a projection-making factor [Jung, CW 9ii, ch. III; CW 17, §338].

**Historical problem.** Jung's descriptions often contain normative assumptions about women, men, rationality, and eros that contemporary analytical psychology does not simply retain. Later revisions must be identified as revisions rather than back-projected into the original text.

### Eros and logos

**[JUNG PRIMARY, HISTORICALLY GENDERED]** Jung frequently links eros to relatedness and logos to discrimination, word, or spirit, and historically maps these unevenly onto women and men. These symbolic polarities can still be examined as psychological functions of relatedness and discrimination, but doing so in a gender-neutral way is already an interpretive revision.

### Power principle

**[JUNG PRIMARY / ADLERIAN CONTEXT]** Jung discusses the will-to-power perspective partly through engagement with Adler. In relationship analysis the "power principle" can name striving for superiority, control, or self-assertion, but it should not be treated as a universal opposite of love or eros. Actual power differences, coercion, material dependence, and social structure require direct analysis rather than symbolic reduction.

---

### Syzygy

**[JUNG PRIMARY, HISTORICALLY GENDERED]** Syzygy means a paired configuration. In *Aion* Jung uses it for the anima-animus pair and its relation to parental and relational projections. The concept belongs to his historical binary model and should not be silently translated into contemporary gender categories.

### Projection of anima/animus

**[JUNG PRIMARY]** Anima/animus projection occurs when qualities organised by Jung's contrasexual inner-figure model are experienced as belonging to an external person, contributing to fascination, idealisation, aversion, and conviction. The presence of attraction alone does not prove anima/animus projection; the hypothesis strengthens when the partner carries an unusually numinous, totalising, or archetypally loaded meaning [Jung, CW 17, §338; CW 9ii, ch. III].

### Later revisions of anima/animus

**[POST-JUNGIAN]** Later analysts variously retain, de-literalise, pluralise, queer, developmentalise, or abandon Jung's sex-polar formulation. Some treat anima/animus as modes of otherness or mediation to the unconscious rather than gendered inner persons. This file does not select a single later revision as authoritative. File 16 and the contemporary handbooks should be consulted for the debate.

### Introjection

**[PSYCHOANALYTIC / POST-JUNGIAN CROSSOVER]** Introjection is the taking-in of aspects of an external object or relationship into internal psychic organisation. It is not a central Jungian technical term comparable to projection, but becomes relevant in developmental and object-relations-informed Jungian work. Do not use it as the automatic inverse of every projection.

## Part V - Post-Jungian Development

### Classical Jungian map - Jolande Jacobi

**[CLASSICAL JUNGIAN]** Jacobi's *The Psychology of C. G. Jung* is an early systematic exposition of Jung's concepts. Its value in this corpus is orientation: psyche structure, complexes, archetypes, functions, dream interpretation, individuation, shadow, anima/animus, and Self are presented as a coherent system.

**Source status.** Jacobi is a close interpreter, not Jung. Where her schematic clarity exceeds Jung's own sometimes shifting terminology, the primary Collected Works remain controlling for claims about what Jung said.

### Inferior-function development - Marie-Louise von Franz

**[CLASSICAL / POST-JUNGIAN]** Von Franz's lectures develop the lived psychology of the inferior function beyond Jung's compact typological description. The inferior function is primitive, emotionally charged, resistant to voluntary control, and close to the figures of the unconscious. She also describes distorted type and the family tendency to distribute functions among members.

**Relationship relevance.** Attraction to an opposite type can initially spare each partner from confronting an inferior function. Development can later require reclaiming what was outsourced to the other. This is a Jungian-developmental account, not an empirical law of mate choice.

### Primary self - Michael Fordham

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Fordham's **primary self** is an original integrated psychosomatic potential present from the beginning of life. It is a developmental reconstruction of the Jungian Self concept, designed to account for infancy rather than waiting for the later emergence of mature ego-Self symbolism.

**Distinguish from Jung's Self.** Jung's mature Self is an empirical totality-and-ordering concept spanning conscious and unconscious. Fordham's primary self is a specific developmental hypothesis. The terms are related historically but not identical.

### Deintegration - Fordham

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Deintegration is the process by which the primary integrated self opens or breaks out into partial systems that engage objects and the environment. It permits contact, learning, and adaptation.

**Not simple fragmentation.** Deintegration is not necessarily pathology. In Fordham it is a normal developmental movement necessary for relationship with the world.

### Reintegration - Fordham

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Reintegration is the return and incorporation of experience after deintegrative engagement. Repeated cycles of deintegration and reintegration enrich the developing self.

**Relational significance.** Fordham makes relationship constitutive of development in a way that shifts classical Jungian emphasis. The infant is not understood as an isolated psyche that only later enters relation.

### Fordham's infant development model

**[POST-JUNGIAN DEVELOPMENT]** Fordham proposes an original undifferentiated or primary self containing archetypal and ego potential; early deintegration allows engagement with caregivers; reintegration modifies the self; ego nuclei develop and organise; and these rhythms continue across development.

**Distinguish from attachment theory.** Although both are developmental and relational, Fordham's model is not Bowlby's attachment behavioural system and does not operationalise safe haven, secure base, attachment anxiety, or avoidance.

### Emergent mind - Jean Knox

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Knox uses an emergent developmental model in which mind, symbolic meaning, and psychological structure arise through interaction among biological predisposition, embodied experience, cognitive development, and relationship.

**Theoretical purpose.** She seeks to preserve what is clinically valuable in archetypal theory while bringing it into dialogue with developmental psychology, attachment theory, cognitive science, and neuroscience.

### Image schema - Knox

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Image schemas are recurring preconceptual patterns abstracted from embodied experience, such as containment, path, balance, or force. Knox proposes them as one way to rethink archetypal pattern without assuming inherited ready-made symbolic images.

**Distinguish from archetype.** In Knox's reconstruction, image schema helps explain how apparently universal symbolic structures may emerge. It is not simply another name Jung used for archetype.

### Internal working model - Knox's Jungian integration

**[POST-JUNGIAN / ATTACHMENT BRIDGE]** Knox brings attachment internal working models into Jungian developmental theory to explain how repeated relationship experiences form implicit expectations of self and other. The source concept remains attachment theory's; Knox's contribution is the integration and reinterpretation within analytical psychology.

### Reflective function - Knox

**[POST-JUNGIAN / DEVELOPMENTAL] Compact definition.** Reflective function is the capacity to experience behaviour as arising from minds with feelings, intentions, beliefs, and motives, including one's own. Knox uses it to explain development of symbolic psychological mindedness and the capacity to hold internal states as representations rather than literal realities.

**Couple relevance.** Under high affect, reflective function can collapse: interpretations of the partner become facts. This overlaps phenomenologically with complex possession and attachment activation, but each framework explains the collapse differently.

### Archetype revision - Knox

**[POST-JUNGIAN DEVELOPMENT]** Knox argues that Jung's writings contain multiple archetype models and that a developmental-emergent account better fits contemporary evidence than a simple inherited-content model. Her position is a revision of Jung, not a neutral restatement.

### Post-Jungian schools - Andrew Samuels

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Samuels proposes a heuristic map of three broad schools of analytical psychology: **classical**, **developmental**, and **archetypal**. Classical approaches prioritise Jung's Self, individuation, and symbolic tradition; developmental approaches give greater weight to early development, transference, object relations, and clinical process; archetypal approaches privilege image, multiplicity, and the autonomous life of psyche.

**Important caution.** Samuels treats the classification as a constructed map, not three sealed institutions. Individual analysts cross boundaries. The map is useful precisely because post-Jungian thought is plural rather than a single doctrinal continuation of Jung.

### Classical School - Samuels

**[POST-JUNGIAN TAXONOMY]** Samuels' **Classical School** is his heuristic label for Jungians who give greatest relative weight to the Self, individuation, symbolic/archetypal material, and continuity with Jung's mature model. It is Samuels' map of the field, not an organisation Jung founded.

### Developmental School - Samuels

**[POST-JUNGIAN TAXONOMY]** The **Developmental School** gives greater relative weight to infancy, ego development, object relations, transference/countertransference, early trauma, and clinical-developmental process. Fordham is a major reference point. The label does not mean developmental analysts abandon archetype or Self.

### Archetypal School - Samuels

**[POST-JUNGIAN TAXONOMY]** The **Archetypal School**, associated especially with Hillman, privileges image, personification, multiplicity, and the autonomous imagination. Samuels stresses overlap among schools; this is a comparative taxonomy rather than a rigid membership system.

### Pluralism - Samuels

**[POST-JUNGIAN]** Pluralism refers to maintaining meaningful differences among Jungian schools and psychological perspectives rather than forcing them into one synthesis. For this Laboratory it becomes a methodological rule: theoretical compatibility must be demonstrated, not assumed.

### Interactive field - Nathan Schwartz-Salant

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Schwartz-Salant's **interactive field** is the experiential field constituted or discovered between two people, especially in analytic work, that contains their mutual subjectivities and, in his Jungian account, an objective/archetypal dimension. He describes it as a "third area" with dynamics not reducible to either participant alone.

**Source development.** Schwartz-Salant explicitly says his field model is heavily indebted to Jung's alchemical transference work while also being distinct from Jung's emphasis on analysing projections. The field is intended to contain the processes an unconscious dyad undergoes and the ways those processes change both participants.

**Distinguish from.** Interactive field is not the same as EFCT negative cycle, attachment bond, systemic feedback loop, or projective identification. Those may describe aspects of the same encounter at different theoretical levels.

### Third area / third thing - Schwartz-Salant

**[POST-JUNGIAN DEVELOPMENT]** The third area is an "in-between" domain of relationship that can be experienced as having its own process. Schwartz-Salant links it to alchemical subtle-body imagery and to a field in which ownership of affect may temporarily be difficult to assign.

**Interpretive caution.** "The field made us do it" is not a responsible use. Individual agency, behaviour, boundaries, and accountability remain necessary distinctions.

### Subtle body - Schwartz-Salant's relational use

**[POST-JUNGIAN DEVELOPMENT]** Borrowing alchemical language, Schwartz-Salant treats subtle body as an intermediate imaginal realm between psyche and matter and uses it as a symbolic precedent for field experience. It should not be converted into a scientifically established energy body.

### Relational coniunctio - Schwartz-Salant

**[POST-JUNGIAN DEVELOPMENT]** Schwartz-Salant moves coniunctio more explicitly into lived interaction: a union-field can emerge when split opposites are contained and experienced in the interactive field. This is an extension of Jung's alchemical psychology, not a synonym for relationship harmony.

### Projective identification

**[PSYCHOANALYTIC CONCEPT USED BY SOME POST-JUNGIANS] Compact definition.** Projective identification is a post-Kleinian psychoanalytic concept in which projected material is understood within an interpersonal process that can pressure, evoke, or organise experience in the recipient. Schwartz-Salant uses the concept in describing field dynamics.

**Distinguish from Jungian projection.** Jungian projection can be analysed as the subject experiencing an inner content as located in an object. Projective identification adds an interpersonal and identificatory process in the recipient. The concepts overlap historically in clinical use but are not equivalents.

### Eight-function archetypal model - John Beebe

**[POST-JUNGIAN DEVELOPMENT] Compact definition.** Beebe develops an eight-function model in which all eight Jungian function-attitudes occupy characteristic archetypal positions. The model joins typology to depth psychology by asking not only *which* function operates but *what archetypal role* organises its use.

**First four positions.** Beebe associates the superior function with **hero/heroine**, the auxiliary with **good parent**, the tertiary with **puer/puella** or child, and the inferior with **anima/animus**. He describes superior-inferior as a "spine" and auxiliary-tertiary as "arms."

**Shadow positions.** The fifth through eighth positions are organised as **opposing personality**, **senex/witch**, **trickster**, and **demonic/daimonic personality**. Beebe explicitly notes the problematic history of terms such as "witch" and discusses both defensive and potentially constructive aspects of shadow positions.

**Source status.** This architecture is Beebe's innovation. Jung did not publish this eight-position archetypal stack.

### Hero / good parent / child / anima-animus positions - Beebe

**[POST-JUNGIAN DEVELOPMENT]** These are archetypal roles through which ego-syntonic functions can be experienced. The hero carries competence and identity; the parent supports, guides, or criticises; the child carries creativity, vulnerability, entitlement, or woundedness; the inferior/anima-animus position carries otherness, ideals, fascination, and deep vulnerability.

**Couple relevance.** Partners can evoke different positions, producing shifts from competence to parental correction, wounded child, or inferior-function sensitivity. This is a rich interpretive model but is not an empirically validated couple taxonomy.

### Opposing personality / senex-witch / trickster / demonic-daimonic - Beebe

**[POST-JUNGIAN DEVELOPMENT]** These are Beebe's shadow-side archetypal function positions. They describe characteristic defensive or destabilising modes, not literal inner characters. "Daimonic" highlights the possibility that the deepest shadow function can also become a source of integrity or transformation rather than remaining purely destructive.

### Love between equals - Polly Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL] Compact definition.** Young-Eisendrath's "love between equals" addresses contemporary adult partnership in which neither person has a socially guaranteed superior role and intimacy therefore requires ongoing differentiation, trust, dialogue, responsibility, and recognition of the other as genuinely other.

**Idealisation and disillusionment.** She describes falling in love as involving idealising projection and treats disillusionment not automatically as evidence of a wrong match but as a developmental opportunity to encounter the particular partner beyond the idealised image.

### Dialogue / mindful witness - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** Her book gives dialogue a central role and explicitly draws on decades of **Dialogue Therapy** developed with Ed Epstein. A mindful witness listens in a way that helps the other become more visible without immediately assimilating the other's experience into one's own assumptions or rebuttal.

**Couple relevance.** Dialogue is not mere turn-taking. It aims to reduce enemy-making, increase accurate witnessing, tolerate difference, and move from idealisation/disillusionment toward compassion and intimacy.

### Differentiation in love - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** Differentiation means allowing each partner to remain a distinct subject rather than demanding completion, mind-reading, or sameness. It is paired with intimacy rather than opposed to it.

**Distinguish from attachment avoidance.** Emotional distance may protect against dependence while leaving the self-other distinction psychologically rigid or defensive. Differentiation involves clearer otherness plus capacity for connection.

### Three Cs: commitment, constraint, containment - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** Young-Eisendrath frames trust around commitment to the relationship, constraint on impulsive or destructive interaction, and containment of emotional extremes. These concepts support an adult partnership capable of surviving disillusionment and difference.

### Soul of the relationship - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES] Compact definition.** Nelson and Delmedico treat the relationship as psychologically meaningful in its own right, speaking of attention to the souls of each partner, the therapist, and the **soul of the relationship**. The phrase marks a specifically Jungian couples stance: therapy attends not only to individual symptom relief but to the symbolic and developmental life of the bond.

**Caution.** This is a contemporary Jungian clinical metaphor, not an entity that can be measured independently of the partners.

### Temenos - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Temenos means a bounded sacred precinct and is used metaphorically for the therapeutic container. In couples work the frame must be strong enough to hold intense affects, projections, complexes, and therapist reactions without collapsing into the couple's conflict.

### Complex-to-complex interaction

**[CONTEMPORARY JUNGIAN COUPLES]** A couple can move from reflective ego-to-ego engagement into interaction organised by constellated complexes. Attention narrows, curiosity drops, old meanings become immediate, and each partner's reaction becomes a trigger for the other's configuration.

**Cross-framework relation.** This can resemble an EFCT negative cycle. The difference is explanatory focus: complex theory emphasises autonomous affective psychic configurations; EFCT emphasises attachment threat, protective moves, and reciprocal interaction.

### Archetypal couple dynamics

**[CONTEMPORARY JUNGIAN COUPLES]** Couple life can constellate mythic and archetypal patterns such as hero-rescuer, parent-child, persecutor-victim, divine couple, trickster, death-rebirth, or conjunction. These patterns can deepen understanding when grounded in actual material. They become flattening when used as prefabricated labels.

### Shadow vows

**[CONTEMPORARY JUNGIAN COUPLES]** Nelson and Delmedico cite their earlier work on **shadow vows**, a formulation for implicit or unconscious commitments that operate alongside explicit relationship vows. Because the 2026 book references rather than fully standardises the concept as a universal technique, this Laboratory uses the term cautiously and routes detailed work to File 21 rather than treating it as settled Jungian doctrine.

### Transferential field in couples therapy - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** The couple and therapist share an emotionally and somatically charged transferential atmosphere. Partners' projections and complexes can draw the therapist into roles, while the therapist's own history and complexes contribute to countertransference. The clinical task includes participation without unconscious enactment.

### Projection, reciprocity, and constellating factor - C. A. Meier

**[POST-JUNGIAN DEVELOPMENT]** Meier's essay on projection and transference argues that ordinary projection is only the starting model. In human relationship there may be a reciprocal "hook," counter-effect, and projection-making factor; subject and object both participate. He proposes increasingly symmetrical models of transference and asks whether some relational configurations require a third or constellating factor rather than one-way causality.

**Source caution.** The Project copy is image-dominant and text extraction is poor. The conceptual route is reliable at the level stated here, but detailed quotation or exact page-level claims should return to the rendered article before use.

### Deintegrates - Fordham

**[POST-JUNGIAN DEVELOPMENT]** Deintegration produces **deintegrates**, partial organisations that emerge from the primary self and engage objects or environmental demands. They are not simply fragments broken off by trauma; in Fordham's normal-development model they are vehicles of contact and adaptation before reintegration.

### Developmental Self - Fordham

**[POST-JUNGIAN DEVELOPMENT]** Fordham reconceives the Self developmentally as active from the beginning of life through rhythmic deintegration and reintegration. This shifts emphasis from a predominantly adult symbolic individuation model toward early relational development.

### Individuation in childhood - Fordham

**[POST-JUNGIAN DEVELOPMENT]** Fordham eventually argues that essential elements of individuation occur from infancy onward. This revises a classical tendency to reserve individuation primarily for later life. It should be attributed to Fordham rather than projected back into Jung without qualification.

### Ego-Self relationship in Fordham

**[POST-JUNGIAN DEVELOPMENT]** Ego organisation develops within the wider activity of the Self rather than beginning as an autonomous centre. Repeated reintegrations contribute to a more stable central ego while the Self remains the wider organising totality.

### Implicit relational knowledge / representation - Knox

**[POST-JUNGIAN / DEVELOPMENTAL]** Knox draws on developmental and attachment traditions in which much relational expectation is encoded implicitly before it can be verbally narrated. Such knowledge shapes anticipation, affect regulation, and behaviour in relationships. It overlaps with internal working models but should not be reduced to explicit beliefs.

### Mentalisation - Knox and adjacent developmental theory

**[POST-JUNGIAN / DEVELOPMENTAL]** Mentalisation is the capacity to understand behaviour in terms of mental states. Knox more often foregrounds **reflective function** in connecting attachment, symbolic thought, and analysis. The terms overlap in their source tradition but are not used here as exact synonyms without source context.

### Agency - Knox

**[POST-JUNGIAN / DEVELOPMENTAL]** Agency is the experience of oneself as an active mental subject whose intentions and actions have effects. Knox links the development of a coherent agentic self to relational experience, reflective function, and symbolic meaning.

### Affect regulation - Knox

**[POST-JUNGIAN / DEVELOPMENTAL]** Knox integrates developmental evidence showing that regulation is initially relational and becomes increasingly internalised. Trauma and defensive organisation can restrict symbolic processing when affect overwhelms reflective capacity.

### Trauma and defensive organisation - Knox

**[POST-JUNGIAN DEVELOPMENT]** Knox locates many defensive patterns in relationship and development rather than treating them solely as expressions of timeless archetypal structure. Trauma can constrain meaning-making, reflective function, and the capacity to revise internal relational models.

### Post-Jungian

**[SAMUELS / FIELD TERM]** "Post-Jungian" names work that develops after and from Jung while revising, extending, criticising, or reorganising his theory. It does not mean anti-Jungian, and it does not imply that later theory is automatically more correct.

### Alchemical / transformational field - Schwartz-Salant

**[POST-JUNGIAN DEVELOPMENT]** Schwartz-Salant uses alchemical symbolism to describe transformations occurring within the interactive field, especially movements through chaos, separation, conjunction, and renewed form. "Transformational field" is best treated as a descriptive family of his field ideas rather than a single fixed construct with operational criteria.

### Embodied / imaginal relational experience - Schwartz-Salant

**[POST-JUNGIAN DEVELOPMENT]** Field experience is not purely cognitive for Schwartz-Salant. Bodily sensation, affect, fantasy, imaginal perception, and shifting subject-object boundaries can all carry information about the encounter. Such experience requires discrimination because it can arise from either participant, the interaction, or the observer's own complex.

### Couple field

**[POST-JUNGIAN / CONTEMPORARY COUPLES]** "Couple field" is useful shorthand for applying relational-field thinking to two partners, but it is not a single canonical Jungian construct. Schwartz-Salant's interactive field and Nelson/Delmedico's transferential field provide stronger source anchors.

### Integrity in type development - Beebe

**[BEEBE]** Beebe's broader type work links mature function use with integrity: each function-position can be expressed defensively or in a way that serves a more coherent personality. Integrity does not mean moral ranking of types or forcing all eight functions into equal development.

### Equality, otherness, intimacy, and mutual recognition - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** "Love between equals" requires recognition that the partner is a distinct subject, not an extension of one's needs. Equality removes traditional role hierarchy as a guaranteed organising principle; **otherness** names the partner's irreducible difference; **intimacy** grows when idealisation gives way to sustained encounter; **mutual recognition** is supported where each can witness and be witnessed without demanding sameness. The book develops these themes through projection, disillusionment, trust, dialogue, and differentiation.

### Expectations of partner - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** Contemporary personal love easily loads the partner with expectations of completion, emotional management, perfect understanding, or validation. Disillusionment exposes the gap between the imagined partner and the actual other, creating either enemy-making or an opportunity for dialogue and differentiation.

### Relational development - Young-Eisendrath

**[POST-JUNGIAN / RELATIONAL]** Relationship development moves, in her account, from idealising projection through inevitable disillusionment toward a more reality-based intimacy grounded in trust, constraint, dialogue, compassion, and acceptance of difference. It is not a fixed stage sequence for every couple.

### Couple individuation - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Couple individuation describes the idea that relationship can have a developmental trajectory while each partner also individuates. The couple is not treated merely as two separate individual treatment cases. Growth can produce a stronger union, a changed form of union, or sometimes a psychologically necessary ending.

### Shadow in couple relationships - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Intimacy makes partners potent carriers for personal and cultural shadow. What remains unspoken, disowned, or morally excluded can organise conflict and attraction. Shadow work must remain linked to actual behaviour and social context.

### Typology in couples - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Typology provides a language for recurring differences in perception, judgment, and tempo. The source cautions, implicitly through its clinical orientation, against reducing partners to labels; type is one lens within a wider analytic field.

### Alchemical couple process - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Alchemical imagery is used to frame relationship as a slow process of differentiation, heating, breakdown, conjunction, and transformation. This extends Jung's alchemical psychology into couple work rather than claiming that Jung himself published a modern couples-treatment protocol.

### Therapist psyche / participation in the field - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** The therapist's body, fantasies, affects, history, and complexes participate in the transferential field. Self-reflection and supervision are therefore part of technique, because the therapist can be drawn into rescuer, judge, parent, ally, abandoned child, or other roles.

### Diversity and contemporary revision - Nelson and Delmedico

**[CONTEMPORARY JUNGIAN COUPLES]** Contemporary Jungian couple practice must revise inherited assumptions about gender, sexuality, family form, culture, and social norm. Diversity is not an optional add-on to classical theory when the classical language itself carries historical norms.

## Part VI - Adult Attachment Theory

### Attachment behavioural system

**[ATTACHMENT THEORY] Compact definition.** The attachment behavioural system is an evolved motivational system organised around obtaining protection, comfort, and felt security from attachment figures when threat, pain, fatigue, separation, loss, uncertainty, or other danger cues activate the system. In Mikulincer and Shaver's adult model, attachment behaviour is not continuously "on" at maximum intensity; it is activated when security is threatened and quiets when protection is restored.

**Normative sequence.** A simplified adult sequence is: perceived threat or distress -> activation of attachment goals -> proximity or contact with an attachment figure, either externally or through mental representation -> assessment of figure availability/responsiveness -> security or secondary strategies -> return, where possible, to exploration and other goals.

**Distinguish from complex.** The attachment system is a species-typical behavioural system with a defined protective function. A Jungian complex is an affectively charged autonomous psychic configuration. A threat can constellate both at once, but one concept does not explain the other away.

**Sources.** Mikulincer & Shaver, *Attachment in Adulthood*, chs. 1-3; Johnson, *Attachment Theory in Practice*, chs. 1-2. Main corpus routes: Files 22 and 23.

## Step 8 — Projection hypothesis

Ask:

- what quality or motive is attributed to the other?
- what supports that attribution?
- what contradicts it?
- does the subjective image exceed available evidence?
- does the partner provide a real hook?

## Step 9 — Type hypothesis

Use only with stable longitudinal evidence.

Do not infer type from silence, emotionality, conflict behaviour, or one difficult decision.

## Step 10 — Recursive interaction

Map how each person's behaviour becomes the other's next event.

Do not infer equal responsibility.

## Step 11 — Accountability

What did each person actually do?

What requires ownership regardless of psychological explanation?

## Step 12 — Repair / boundary / decision

Possible domains:

- factual acknowledgement;
- responsibility;
- emotional recognition;
- attachment responsiveness;
- behavioural change;
- restitution;
- trust rebuilding;
- projection differentiation;
- dialogue;
- boundary;
- incompatibility;
- reconciliation;
- separation.

## Step 13 — Developmental hypothesis

Only last ask whether the episode may participate in:

- projection withdrawal;
- differentiation;
- integration of opposites;
- individuation;
- developmental renegotiation.

Do not infer individuation from a preferred relationship outcome.

# 10. Relationship safety and accountability rules

The corpus must never allow psychological sophistication to erase ordinary reality.

Always preserve the possibility of:

- genuine incompatibility;
- betrayal;
- broken agreements;
- deception;
- coercion;
- unequal power;
- practical conflict;
- legitimate anger;
- justified boundaries;
- one-sided harm.

A projection may be present while the other person is also behaving badly.

A complex may be constellated while conduct still requires accountability.

An attachment cycle may be reciprocal while one person's behaviour is materially more harmful.

Emotional reconnection is not a substitute for behavioural change.

Forgiveness is not a prerequisite for repair.

Repair is not a mandate to reconcile.

# 13. Starter prompts

## Complex vs attachment

```text
Compare Jungian complex activation and attachment-system activation.
Do not merge them.
State the unit of analysis, mechanism, phenomenology, evidence, and limits of each.
Then explain how both might plausibly operate in the same episode without being identical.
```

## Projection

```text
Explain projection using Jung primary sources first.
Then compare Jungian projection with attachment expectation and ordinary misinterpretation.
Use examples only as examples, not as evidence that projection is present.
```

## Individuation

```text
Using Jung primary files first, explain individuation.
Then distinguish it from independence, secure attachment, authenticity, relationship satisfaction, staying together, and leaving.
Label all contemporary comparisons as later comparison or Laboratory synthesis.
```

## Type

```text
Explain this recurring difference using Jungian typology only if there is stable longitudinal evidence.
Do not use MBTI shorthand.
Distinguish attitude, function, inferior-function dynamics, complex activation, and attachment threat.
```

## Couple cycle

```text
Map this episode first as observable behaviour.
Then compare EFCT negative-cycle formulation, adult attachment activation, Jungian complex activation, projection, Greenberg emotion processing, and ordinary contextual explanations.
For each model state what it adds and what it cannot establish.
Do not infer equal responsibility from mutual influence.
```

## Repair

```text
Analyse what repair would require across factual acknowledgement, responsibility, emotional recognition, attachment responsiveness, behavioural change, trust, projection differentiation, dialogue, boundaries, forgiveness, reconciliation, and relationship preservation.
Keep these dimensions separate.
Do not assume that repair requires staying together.
```
